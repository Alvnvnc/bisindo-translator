KelasSampelAksi

Setiap rekaman diberi ID sesi otomatis dan ID periset. Ini penting untuk teori data: model harus diuji pada periset yang belum pernah dilihat sistem (signer-independent), kalau tidak akurasinya palsu. Setelah cukup data (target ≥ 300 sampel/kelas dari ≥ 3 periset), ekspor CSV lalu simpan ke data/samples/ dan jalankan python scripts/train.py.
