ClassSamplesAction

Every recording gets an automatic session ID and a signer ID. This matters for correct methodology: the model must be evaluated on signers it has never seen (signer-independent), otherwise accuracy numbers are misleading. Once you have enough data (target ≥ 300 samples/class from ≥ 3 signers), export the CSV into data/samples/ and run python scripts/train.py.
